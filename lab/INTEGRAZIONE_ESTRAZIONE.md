# Integrazione contenuti estratti — stato verificabile

I contenuti completi estratti sono disponibili nel pacchetto locale `REM_laboratorio_modulare.zip` fornito in conversazione, **non ancora caricati nel ramo GitHub**.

Il catalogo `lab/catalog/books.json` sul ramo contiene ora i percorsi di destinazione per i due file di contenuto, ma questi percorsi non sono ancora risolti nella demo GitHub. Non considerare questa modifica una migrazione funzionante.

Il pacchetto locale contiene 452 segmenti per Montecristo e 278 per Casa; la nuova iterazione del pacchetto offre navigazione per capitolo, Focus con pausa/riprendi/termina, durata selezionabile e progressi locali.

Per una pubblicazione GitHub corretta occorre aggiungere entrambi i file JSON estratti sotto `lab/content/`, aggiornare il lettore della demo a consumarli, eseguire i test e verificare Safari iPhone. Nessuna modifica a main o alla versione ufficiale.
